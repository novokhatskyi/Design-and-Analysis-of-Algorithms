## Завдання 1. Пошук максимального та мінімального елементів

### Умова

Потрібно реалізувати функцію, яка знаходить мінімальний та максимальний елементи в масиві чисел довільної довжини, використовуючи рекурсивний підхід **«розділяй і володарюй»**.

### Алгоритмічна ідея

Масив рекурсивно ділиться на дві частини. Для кожної частини окремо знаходяться мінімальне та максимальне значення. Після цього результати двох частин об’єднуються: загальний мінімум обирається як менше з двох мінімумів, а загальний максимум — як більше з двох максимумів.

### Базові випадки

- Якщо в підмасиві один елемент — він одночасно є мінімумом і максимумом.
- Якщо в підмасиві два елементи — вони порівнюються між собою, після чого повертається пара `(min, max)`.

### Результат роботи функції

Функція повертає кортеж:

```python
(min_value, max_value)
```

### Складність

Часова складність алгоритму:

```text
O(n)
```

Кожен елемент масиву бере участь в обробці обмежену кількість разів, тому загальна складність залишається лінійною.

### Виконані критерії

- Функція приймає масив чисел довільної довжини.
- Використано рекурсивний підхід.
- Повертається кортеж значень `(мінімум, максимум)`.
- Складність алгоритму — `O(n)`.

## Завдання 2. Оптимізація черги 3D-принтера

### Умова

Потрібно розробити програму для оптимізації черги завдань 3D-друку в університетській лабораторії.

Кожне завдання на друк містить:

- `id` — унікальний ідентифікатор моделі;
- `volume` — об’єм моделі в см³;
- `priority` — пріоритет завдання;
- `print_time` — час друку в хвилинах.

Також задано технічні обмеження принтера:

- `max_volume` — максимальний сумарний об’єм моделей для одного друку;
- `max_items` — максимальна кількість моделей, які можна друкувати одночасно.

---

## Пріоритети завдань

| Пріоритет | Опис |
|---|---|
| 1 | Курсові та дипломні роботи |
| 2 | Лабораторні роботи |
| 3 | Особисті проєкти |

Завдання з меншим числовим значенням пріоритету мають виконуватися раніше.

---

## Алгоритмічна ідея

Для оптимізації використовується **жадібний алгоритм**.

Основні кроки:

1. Вхідні словники перетворюються на об’єкти `dataclass`.
2. Завдання сортуються за пріоритетом.
3. Завдання послідовно додаються до поточної групи друку.
4. Перед додаванням кожної моделі перевіряються обмеження:
   - чи не перевищено максимальну кількість моделей;
   - чи не перевищено максимальний сумарний об’єм.
5. Якщо модель не можна додати до поточної групи, поточна група завершується, а з цієї моделі починається нова група.
6. Час друку кожної групи визначається як максимальний час друку серед моделей у цій групі.
7. Загальний час обчислюється як сума часів усіх груп.

---

## Час друку групи

Якщо кілька моделей друкуються одночасно, час друку групи дорівнює максимальному часу серед моделей у групі.

Наприклад:

```text
M1: 120 хв
M2: 90 хв
```

Якщо ці моделі друкуються разом, час групи буде:

```text
max(120, 90) = 120 хв
```

## Структури даних

У програмі використовуються `dataclass` для опису завдань друку та обмежень принтера.

```python
@dataclass
class PrintJob:
    id: str
    volume: float
    priority: int
    print_time: int

@dataclass
class PrinterConstraints:
    max_volume: float
    max_items: int
```

Використання `dataclass` робить код більш структурованим, зрозумілим і зручним для роботи з об’єктами.

Функція `optimize_printing` повертає словник такого формату:


де:

- `print_order` — порядок друку моделей;
- `total_time` — загальний час виконання всіх завдань у хвилинах.

## Тестові сценарії

У роботі перевіряються такі випадки:

1. Моделі однакового пріоритету.
2. Моделі різних пріоритетів.
3. Ситуація, коли моделі не можна згрупувати через перевищення обмежень принтера.

---

## Виконані критерії для завдання 2

- Програма групує моделі для одночасного друку.
- Під час групування не перевищуються обмеження `max_volume` та `max_items`.
- Завдання з вищим пріоритетом виконуються раніше.
- Час друку групи моделей розраховується як максимальний час серед моделей у групі.
- Програма обробляє всі тестові сценарії.
- Для структур даних використано `dataclass`.
